# Excel 同步：只用 sunburst、小变化以换主体为主、二次大变化（2026-10-27）

## 为什么改

- 用户 2026-10-27 说小变化里主体变化太少，小变化很多但出来的图都非常相似；颜色、装饰这类变化不明显，主体的变化最明显。要把小变化变少、其中大量是主体变化；大变化里一部分照旧基于原图，另一部分基于已经改过主体的小变化再做一轮大变化，让所有图的变化都明显。用户选「每个小变化至少一处是换主体本身」「等小变化出完图，程序自动挑换了主体的小变化，以它出的图当底图再策划一轮大变化」。
- 同日又要求只从 gpt-image-2.5-sunburst 出图；只有一个生图模型了，每个方向出的图少了一半，所以小变化和大变化的量都多一些；小变化里 80% 有主体变化（换主体）。

## P14 换主体清单（新增提示词，全文）

### 输入

{{swap_units}}、{{reference_profile}}、{{family_rules}}、{{user_direction_request}}。swap_units 是这一轮要换主体的可变单元：unit_id、名字、类型（character 角色 / object 物件主体）、成员、拆解里主体的现状（current）、要给几个新主体（need）、以前换过和提过的（done）。reference_profile 是参考图的完整画面档案（画风、配色、每个主体、环境、构图与画风统一规则）。

### 角色与任务

你是题材策划。同一张参考图这一轮要出很多个「换主体」的方向，每个方向把一个单元里的主体整个换成另一种。你先给每个单元列一份新主体清单，程序按顺序把清单分给各个方向，保证同一批里每个方向换成的主体都不一样。

### 执行规则

每个单元给 need 个候选，彼此明显不同：不同物种、不同类别（如北极熊、海豹、企鹅、狐狸是四种；小企鹅和帝企鹅算同一种，橘猫和狸花猫算同一种），不只换颜色、品种、大小或姿态。候选和参考图同一个题材与受众（儿童动物图换成别的儿童喜欢的动物或角色，太空物件换成别的太空物件），能用参考图同一套画风画出来、放在原来的位置和姿态里协调。角色单元给动物、拟人角色这类有脸的主体；物件单元给同主题的另一种物件（游戏手柄换成耳机、复古相机，满月换成土星、彗星）。组单元（成员不止一个）给的是一整组：name 写成员一一对上的新组合（如「北极熊、海豹、企鹅」），成员个数与原来相同。不能和 done 里任何一个重复或只是换个说法，也不能和参考图原来的主体相同。family_rules 的排除项照常遵守：不出现可识别的既有角色、品牌、IP 形象和商标，不出现攻击、恐怖或成人内容。user_direction_request 不是「没有额外要求」时，候选尽量往这个要求靠。

### 输出约定

result={"units":[{"unit_id":"U01","candidates":[{"name":"北极熊","en":"a round baby polar bear","features":"白色厚毛、黑鼻头、圆耳、短粗四肢"}]}]}。swap_units 里每个单元都要有一项，unit_id 照抄；candidates 按推荐顺序排，每个写 name（中文，不超过 12 个字）、en（英文名词短语，能直接写进生图提示词）、features（标志性特征，让人和模型一眼认出是这种主体，不超过 40 个字）。

### 结束与回流

想不出 need 个时少给几个，不凑数、不重复；程序会把清单不够的方向交给 P05 自己换。
