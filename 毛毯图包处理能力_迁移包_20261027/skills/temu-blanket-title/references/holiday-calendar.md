# Ecommerce Holiday Calendar

Use this calendar to decide whether a product is holiday-led. Only mark a product as holiday-led when the image clearly matches one of these ecommerce holidays or marketing nodes.

If a product is holiday-led, put the holiday name within the first 5 words of the title.

## Title Wording

Prefer common ecommerce title wording:
- `Christmas`
- `Halloween`
- `Valentine`
- `Easter`
- `Thanksgiving`
- `Mother's Day`
- `Father's Day`
- `Independence Day`
- `Patriotic`
- `St Patrick's Day`
- `New Year`
- `Super Bowl`
- `Earth Day`

## Cautions

- `May The Fourth` can create IP risk. Prefer generic `Space Theme` unless the user explicitly confirms a compliant generic design.
- `Black Friday`, `Cyber Monday`, and `National Free Shipping Day` are promotion nodes. Do not use them in a product title unless the image itself clearly contains that theme.
- Use `Love Your Pet Day` carefully. Do not write `Pet Blanket`; use `Dog Lover Gift`, `Cat Lover Gift`, or `Pet Lover Gift` when suitable.
- Political, patriotic, military, and memorial holidays should only be used when the visual design clearly supports them.
